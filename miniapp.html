Установка на VPS

Автоматическая установка Black Russia Bot и запуск Telegram-управления.

📖 Инструкция: Windows, Linux, Termux и macOS

Только для VPS с Ubuntu 26.04 LTS.
Введите публичный IP, логин и пароль VPS. SSH подключается автоматически; нужен root или sudo без пароля. Установщик настроит Git, Python, зависимости (в том числе telebot), sing-box и системную службу.

Сравните отпечаток с данными в панели VPS-провайдера или другим доверенным источником. Если ключ не совпадает или его не удалось проверить, не продолжайте.

Можно вставить данные кнопкой «Вставить» или удерживать поле и выбрать вставку. На некоторых устройствах доступ к буферу может быть ограничен.

Пароль и токен передаются нашему серверу по HTTPS для установки. Пароль VPS не сохраняется на нашем сервере; токен записывается в закрытый конфигурационный файл на вашем VPS для запуска бота.

Панель добавится в меню установленного бота. Для HTTPS нужны свободные порты 80 и 443; доступ — только через Telegram администратора.

Соединение действует 10 минут без действий; пароль не сохраняется.

Действие выполняется сразу после нажатия. При обновлении запущенная программа будет ненадолго остановлена.

Мост работает с вашими VPN-узлами. Добавьте подписку в меню «Прокси и VPN» установленного бота или в его панели.

Lua-скрипты и боты

Файлы загружаются на VPS, без автоматического запуска. Только доверенные скрипты.

Мои покупки

Выберите оплаченный Lua-файл. Файл будет добавлен в scripts/lua без автоматического запуска.

Настройки JSON: любые названия, строки, числа, переключатели, списки и вложенные объекты. Скрипт должен читать их через br.setting; токен автокапчи вводите отдельно.

ИИ для автокапчи

Нужна сборка игрового бота с новой ИИ-автокапчей. Токен не отображается после сохранения.

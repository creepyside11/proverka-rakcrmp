# Подготовка Lua-раздела Mini App

Изменения подготовлены для текущей версии репозитория `creepyside11/proverka-rakcrmp`. В Mini App: VPS → «Управление установленной программой» → проверить IP, ввести SSH-логин и пароль, сверить отпечаток → «Lua: скрипты и настройки». После подключения можно загрузить текстовый `.lua` (до 256 КиБ), посмотреть список файлов, сохранить настройки скрипта, временно отключить их и заполнить настройки ИИ-автокапчи. Файл с уже существующим именем не перезаписывается. Само сохранение **не запускает** скрипт.

SSH-подключение закрепляется за Telegram-пользователем, закрывается после 10 минут бездействия либо кнопкой «Закрыть подключение». Пароль не записывается на диск. API Token сохраняется только в `/opt/rakcrmp-black/.env` с правами 0600, в ответе панели не возвращается. Настройки скриптов находятся в `/opt/rakcrmp-black/.lua-settings/`, скрипты — в `/opt/rakcrmp-black/scripts/lua/`. При обновлениях следует сохранять эти данные, не делать `git clean`, `reset --hard` или принудительную замену. Встроенный обновлятор по-прежнему отказывается от конфликтующего обновления. Значения `CAPTCHA_*`, заданные непосредственно в окружении службы, имеют приоритет над `.env`.

Настройки — JSON-объект с произвольными названиями, строками, числами, булевыми значениями, списками и объектами, до 16 КиБ и 6 уровней вложенности. Скрипт должен самостоятельно использовать `br.setting` / `br.settings`, старый скрипт автоматически понимать их не начнёт. Общая галочка выключает передачу значений, но не сам скрипт. Не передавайте секреты через Lua-настройки; для ИИ предусмотрено отдельное поле.

## Обязательно про установленную версию

Нынешний установщик VPS закреплён на ревизии `ad324c9eeb6a0022aed4ac31203c04b670d324fc` репозитория `black`. В ней нет полного `logic/lua_runtime.py` и новой `logic/openai_captcha.py`. Поэтому только обновление `proverka-rakcrmp` добавит интерфейс сохранения, но **не установит и не запустит Lua-загрузчик или новую ИИ-капчу на VPS**. Панель отобразит, каких модулей нет. Комплект игровой версии с поддержкой настроек подготовлен отдельно, но безопасная миграция существующей установки и обновление её системной службы здесь не реализованы. Нельзя подменять файлы установленной программы без согласованного обновления и проверки, чтобы не сломать работающую установку или существующий обновлятор.

Проверки: `python -m unittest discover -s tests -p 'test_vps_*.py' -q` и `python -m unittest discover -s tests -p test_miniapp.py -q`. Тесты используют локальную SSH-службу и подставные данные; настоящий VPS и Telegram-панель не проверялись.

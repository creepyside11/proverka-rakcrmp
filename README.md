# RakCRMP — бот-модератор тем Telegram

Модератор для супергруппы с темами: у каждой темы свои фильтры, список запрещённых слов и автосообщение. Настройки и заказы хранятся в PostgreSQL. Управление — кнопками или командами. В личном чате администратора доступны /admin и /test_captcha; последняя команда запускает тест капчи в Mini App без ограничений участника. Для запуска нужны токен Telegram-бота и числовой ID владельца.

## Важное о проверке файлов

Это **эвристический статический анализатор, а не полноценный антивирус**. Он не запускает пользовательский код. Если бот написал, что известных опасных признаков не найдено, это не гарантия безопасности. Вредоносный код может обойти проверку; возможны ложные срабатывания. Не запускайте непроверенные файлы на основном устройстве и не используйте надпись бота как гарантию безопасности.

Бот ищет некоторые опасные вызовы и команды, проверяет простые Lua-экранирования, некоторые строки Base64 и содержимое gzip в ограниченном объёме. Это не универсальное расшифрование: произвольные шифры, упаковщики и обфускацию автоматически раскрыть нельзя. `.luac`, нераспознанные бинарные файлы и динамическая загрузка считаются **непроверенными**, если опасные признаки не обнаружены. По умолчанию бот их удаляет; настройку можно поменять в каждой теме, но при этом файл останется с предупреждением. При обнаружении опасных признаков бот удаляет файл с указанием причины; это не подтверждение заражения. Файлы больше 5 МиБ и ошибки скачивания также считаются непроверенными. Архивы и файлы с другими расширениями не проверяются; для ограничения других файлов включите режим «Только Lua/Luac».

## Установка на Termux

1. Создайте бота через [@BotFather](https://t.me/BotFather) и сохраните токен. Узнайте свой **числовой ID Telegram** (не `@username`), например, у информационного Telegram-бота. Не публикуйте токен.
2. Установите Termux из актуального источника и выполните:

```sh
pkg update && pkg upgrade
pkg install python git
git clone https://github.com/creepyside11/proverka-rakcrmp.git
cd proverka-rakcrmp
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
```

3. В `.env` заполните ровно два параметра:

```dotenv
BOT_TOKEN=токен_из_BotFather
ADMIN_ID=123456789
```

Сохранение в nano: Ctrl+O, Enter, Ctrl+X. В Termux Ctrl обычно вводится через дополнительную клавишу Ctrl или сочетание громкость вниз + нужная буква.

4. Создайте супергруппу, включите в ней **Темы**, добавьте бота администратором и выдайте права **удалять сообщения** и **блокировать пользователей**, а также возможность писать в группу. Бот-администратор получает сообщения группы; при проблемах с получением проверьте privacy mode у BotFather (`/setprivacy`) и после смены настроек пере-добавьте бота в группу. Ограничения Telegram и права администратора группы по-прежнему действуют: чужого администратора бот может не суметь модерировать. Добавьте бота до проверки работы.
5. Запустите:

```sh
python bot.py
```

Бот должен работать постоянно. На Android Termux может останавливаться системой: отключите для него экономию батареи, используйте `termux-wake-lock` и при необходимости `tmux` или сервер. Если терминал или телефон выключен, бот не работает. Запускайте только один экземпляр с одним токеном и базой. Для запуска требуется `DATABASE_URL` PostgreSQL. Регулярно делайте резервную копию базы. Не публикуйте `.env` и базу.

## PostgreSQL и магазин

Заполни переменные окружения на хостинге (или в локальном `.env`):

- `BOT_TOKEN` и `ADMIN_ID` — токен бота и числовой Telegram ID владельца.
- `DATABASE_URL` — строка PostgreSQL, например `postgresql://user:password@host:5432/database` (для облачной базы могут потребоваться параметры SSL от провайдера).
- `CRYPTO_PAY_TOKEN` — токен приложения Crypto Pay; `CRYPTO_PAY_TESTNET=1` включает тестовую сеть Crypto Bot.
- `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET` — данные Platega. СБП и карты должны быть подключены в кабинете Platega.
- Кнопка «Поддержать проект» создаёт счёт Crypto Bot, СБП или карты через те же реквизиты; пользователь вводит сумму от 1 ₽. Платёжный сервис может устанавливать собственный минимум.

Бот запускается одной копией; проверка платежей происходит в фоновом цикле и по кнопке покупателя. Провайдер подтверждает статус, сумму, валюту и привязку к заказу. При успешной оплате бот отправляет Lua-файл и инструкцию, которые были сохранены при оформлении заказа. При ошибке доставки платный заказ остаётся на повторную отправку. После сбоя непосредственно между отправкой в Telegram и записью в базу возможна повторная доставка: Telegram не предоставляет ключ идемпотентности для `sendDocument`.

**Переход с существующей версии:** останови бота, сохрани резервную копию SQLite вместе с WAL, укажи `DATABASE_URL`, затем выполни `python migrate_sqlite.py /путь/к/moderator.sqlite3`. Импорт допустим только в пустые таблицы модерации PostgreSQL; скрипт не изменяет SQLite. После успешного переноса запусти `python bot.py`. Не запускай одновременно старую и новую версии.

Донаты сохраняются отдельно от заказов; после подтверждения бот отправляет благодарность без выдачи Lua-файла.

В личном чате отправь `/admin`, нажми «Добавить товар» и по шагам укажи категорию, название, описание, цену в рублях, инструкцию и файл `.lua` документом. В «Управлении товарами» можно скрыть или снова опубликовать товар. `/cancel` отменяет добавление. Ссылки на продукты будут доступны в соответствующем каталоге после публикации.

Сначала проверь оплату в тестовой среде и доставку на тестовом аккаунте. Платёжные реквизиты не отправляй покупателям и не коммить в Git. По правилам Telegram продажа цифровых товаров внутри ботов и мини-приложений должна проводиться через Telegram Stars; сторонние способы оплаты могут привести к ограничениям бота: https://core.telegram.org/bots/payments-stars.

## Капча для новых участников

Капча включается автоматически для новых участников супергруппы; текущих участников она не затрагивает. Дополнительных параметров в `.env` не требуется. Выдайте боту права администратора **«Блокировка пользователей»** и **«Удаление сообщений»**. Бот получает события вступления как администратор.

1. При вступлении бот ограничивает участника и отправляет в группу личную ссылку на проверку.
2. Участник открывает ссылку, нажимает «Начать» в личном чате бота и запускает Mini App с капчей. Подписка на канал для капчи не требуется.
3. На ответ есть 10 минут и три попытки. Ответ может отправить только та учётная запись, которой выдана проверка.
4. После правильного ответа бот снимает ограничение. После трёх ошибок или истечения времени бот удаляет участника и снимает бан, чтобы он мог вступить заново.

Проверку администратор может запустить командой `/test_captcha`; тест не меняет права участников. Доступность Mini App зависит от работающего HTTPS-домена `rakcrmp.bothost.tech`.

Состояние, оставшиеся попытки и срок хранятся в PostgreSQL. Пока бот выключен, ограничения сохраняются, но немедленно кикнуть пользователя он не может: после запуска обработает просроченные проверки. При сетевой ошибке удаления, разблокировки или снятия ограничения повторит действие. Участников с уже имеющимися индивидуальными ограничениями и администраторов бот не обрабатывает, чтобы не менять их права. При отсутствии права ограничивать участников бот сообщает об ошибке и не объявляет, что проверка включена. Если кто-то вручную изменит права участника во время проверки, итоговые права нужно проверить вручную. Капча с арифметическим примером затрудняет простой спам, но не защищает от решателей и автоматизированных ботов.

## Настройка конкретной темы

Команды отправляет только пользователь с `ADMIN_ID`. Остальные пользователи, включая других администраторов группы, не могут менять настройки. Отправьте команду **именно внутри нужной темы**; общая тема и другие темы независимы. Для общих настроек отправьте в общей теме.

- `/panel` — интерактивные кнопки включения фильтров. ✅ — включено.
- `/config` — показать настройки и идентификаторы чата/темы.
- `/filter insults on` — включить фильтр оскорблений по списку слов.
- `/filter ads on` — запретить ссылки, упоминания и часть похожих адресов.
- `/filter luaonly on` — запретить сообщения без прикреплённого `.lua` или `.luac`; подписи допускаются и проверяются текстовыми фильтрами.
- `/filter unknown_delete off` — оставить непроверенные файлы с предупреждением. `on` — удалять, включено по умолчанию.
- `/filter scan off` — отключить проверку файлов в теме. По умолчанию включена; не рекомендуется отключать.
- `/word add слово`, `/word del слово`, `/words` — настроить слова темы. Поиск идёт по точному слову без учёта регистра; склонения и обходы не гарантированно распознаются.
- `/autopost 60 Не скачивайте файлы без проверки!` — отправлять текст каждые 60 минут. Диапазон — от 1 до 525600 минут; первое сообщение приходит через заданный интервал.
- `/autopost off` — отключить автосообщение темы.
- `/help` — справка.

Для любого `/filter` используйте `on` или `off`. Владелец освобождён от текстовых ограничений и правила «только файлы», чтобы мог управлять группой; его Lua-файлы всё равно проверяются. Фильтр ссылок может блокировать обычные ссылки, а не только рекламу. Удалённые сообщения восстановить бот не может. Сообщения об ошибках и удалениях остаются в теме. Изменённые сообщения обрабатываются повторно.

## Обновление

Остановите бота Ctrl+C, создайте резервную копию базы, затем:

```sh
git pull
. .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Не храните изменения `.env` в Git. Для тестов без Telegram-токена: `python -m unittest discover -s tests -v`. Для реальной проверки необходимы тестовая супергруппа, работающий токен и права на удаление; тесты не подтверждают качество обнаружения всех угроз. Периодические сообщения сохраняются в БД: после перезапуска просроченное отправляется один раз; при сбое во время отправки одна публикация может пропуститься. Удалённая или закрытая тема может вызывать ошибки отправки в журнале.

### Капча, подписка и рассылка

Капча новых участников супергруппы открывается в Mini App: случайный пример или выбор эмодзи. Подписка на каналы к групповой капче отношения не имеет. Для теста администратор отправляет `/test_captcha`.

В личном чате владельца доступны `/admin`, `/stats`, `/channels`, `/addchannel @username`, `/delchannel @username` и `/broadcast текст`. Перед добавлением канала сделайте бота администратором канала. Для частного канала используется `/addchannel -100ID https://t.me/+пригласительная_ссылка`. Список каналов общий для личного использования бота всеми пользователями; их подписка проверяется при каждом действии. При ошибке проверки доступ не предоставляется. Владелец исключён из проверки. `/stop` отключает рассылку, `/subscribe` включает обратно.

Рассылка доставляется только пользователям, которые написали боту `/start` после установки обновления и не отключили рассылку; Telegram не позволяет боту первым писать произвольным участникам группы. Перед запуском владелец видит текст и количество получателей и подтверждает отправку. Бот показывает итог; при перезапуске незавершённая рассылка не возобновляется. Статистика пользователей и завершённых капч накапливается начиная с установки обновления, прошлые события не восстанавливаются.

### Магазин Telegram Mini App

Магазин открывается кнопкой в личном чате бота и размещается по адресу `https://rakcrmp.bothost.tech/`. Веб-сервер запускается вместе с ботом, слушает `0.0.0.0` и переменную окружения `PORT` (по умолчанию 3000). В Bothost назначьте этот домен контейнеру бота и убедитесь, что порт прокси совпадает с `PORT`. Действующий `BOT_TOKEN`, `ADMIN_ID` и `DATABASE_URL` остаются обязательными.

Товары добавляются через `/admin`. Для оплаты в магазине установите отдельную цену в Telegram Stars: в личном чате администратора `/stars` показывает ID товаров, `/stars ID 100` задаёт цену 100 ⭐. До установки цены в Stars этот способ оплаты недоступен; другие методы используют рублёвую цену товара. Цены в рублях автоматически в Stars не переводятся. В существующем добавлении товаров принимаются файлы `.lua`, в том числе для категории ботов.

Магазин проверяет подпись и срок действия Telegram `initData`, а также обязательную подписку, настроенную в боте. В Mini App доступны Stars, СБП, карта и Crypto Bot; для последних необходимы настройки платёжных провайдеров. Telegram требует Stars для продажи цифровых товаров внутри Telegram, сторонние способы могут привести к ограничениям бота. Оплаченный файл и инструкция отправляются в личный чат; при ошибке отправки выдача повторяется. При сбое непосредственно после успешной отправки Telegram может прийти повторное сообщение. `/paysupport` доступна пользователям, в том числе при отсутствии подписки. Старые платежи и кнопки магазина бота не заменяются этим обновлением.

### Автоустановка Black Russia Bot на VPS

В личном чате бота выберите «Установить на VPS» или откройте вкладку VPS в Mini App. Установщик предназначен только для принадлежащего пользователю VPS с Ubuntu 26.04 LTS, публичным числовым IP и SSH на порту 22. Нужны учётная запись root либо пользователь с `sudo -n`, пароль SSH, токен нового Telegram-бота и числовой ID его администратора.

Перед передачей SSH-пароля приложение показывает SHA256-отпечаток ключа сервера. Его необходимо сверить с отпечатком из панели хостинга или другого доверенного источника. При несовпадении подключение не выполняйте. После явного подтверждения установщик подключается по SSH с проверкой этого ключа, устанавливает системные пакеты и зависимости из `requirements.txt` в виртуальное окружение, включая pyTelegramBotAPI (`telebot`), скачивает закреплённую версию `creepyside11/black` и создаёт службу `rakcrmp-black.service`. Sing-box 1.11.15 скачивается из официального релиза, проверяется по SHA-256 и устанавливается отдельно в `/opt/rakcrmp-black-runtime/sing-box`, не заменяя системную копию. Используются `/opt/rakcrmp-black`, `/opt/rakcrmp-black-runtime`, системный пользователь `rakcrmp-black`, `/etc/rakcrmp-black/bot.env` и unit-файл systemd. Если каталог, пользователь или служба уже существуют, установка прерывается без перезаписи. При сбое установки созданные ранее файлы могут остаться на VPS.

Пароль SSH и токен передаются через HTTPS в сервер Mini App на время операции. SSH-пароль не записывается в базу или журнал намеренно. Токен сохраняется на VPS в `/etc/rakcrmp-black/bot.env` с правами только root, потому что он нужен для автозапуска. Результат задания хранится в памяти приложения до часа; после перезапуска основного бота история задачи может пропасть. Проверка статуса службы не гарантирует, что введённый токен работает или аккаунты подключились к игре. Если бот уже запущен с этим токеном на другой машине, сначала остановите его там.

При установке сначала укажите IP: стандартный SSH-порт 22 выбирается автоматически. После проверки сервера появятся поля логина, пароля и данных бота, а также отпечаток SSH-ключа для сверки. У полей есть кнопка вставки из буфера; если Telegram или браузер запрещает автоматическое чтение буфера, удерживайте поле и выберите «Вставить» в меню или используйте буфер клавиатуры. Подключение может не работать, если VPS недоступен, SSH выключен, порт 22 закрыт на VPS или исходящий SSH ограничен хостингом бота.

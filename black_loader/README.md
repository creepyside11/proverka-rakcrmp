# Подготовленные компоненты Lua для Black

Это исходные файлы Lua-загрузчика и ИИ-капчи для игрового проекта. Они находятся здесь для подготовки будущего обновления. Само размещение в этом репозитории **не устанавливает их на VPS**: действующий установщик использует другую версию `creepyside11/black`, а безопасная миграция текущей установки пока не реализована.

Мини-приложение позволяет загрузить и перечислить `.lua` на VPS и сохранить настройки. Для выполнения Lua и чтения настроек соответствующий игровой проект должен содержать полноценный интегрированный загрузчик. После загрузки файл автоматически не запускается. `br.setting()` и `br.settings()` доступны только в обновлённом загрузчике; старые скрипты должны явно читать нужные параметры. Токен ИИ хранится отдельно, не в настройках Lua.
